# Gear + Belt Drive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two new joint kinds — **gear** (mesh: opposite spins, ratio = rA/rB) and **belt** (same-direction drive) — between circle bodies, using the velocity-level seam the shipped pulley established.

**Architecture:** Per-tick velocity-level solve next to `applyPulleyTension` in `PhysicsWorld.step()` (`src/lib/gears.ts` pure solver + `world.ts` walk). Angular impulses drive Ċ → −bias where C = θA·rA + m·θB·rB with m = +1 for a gear (mesh — the spins OPPOSE; the constraint is the arc-length SUM) and m = −1 for a belt (same direction; the arc-length DIFFERENCE), rA/rB = the circles' own radii captured at placement [sign corrected post-hoc from the original "(minus = gear, plus = belt)" — the sum form is the mesh; pinned by tests/unit/gears.test.ts and e2e/gears.pw.ts], bias = Baumgarte phase correction anchored to the placement orientation (so drawn teeth stay meshed). The gears stay ordinary physics bodies — mounting on axles is the user's pin joints; tooth contact is never simulated. Two PlaceableJointKind entries ("gear", "belt") share the placement flow and the params shape `{ kind, ratio, phaseA, phaseB }` (phase offsets from placement), differing only in the coupling sign.

**Tech Stack:** TypeScript strict, Rapier2D-compat 0.21 (no new dependency), bun test, Playwright e2e.

**Spec:** Approved design in session 2026-10-24 (kanban card `01a17056c9cc70709c9f8c4cdb1fe93f` notes): gears are circles only (non-circle clicks refuse with a visible notice); teeth are decorative glyph overlays, NOT colliders — sprite cache and body shapes untouched; ratio is not editable post-placement (delete + re-place); read-only panel readouts; belt mode draws a tangent trace between the circles.

## Review Focus

- Sign errors: mesh must OPPOSE spins, belt must MATCH them; the bias must hold phase, not drift.
- Motor-driven train: a motor on gear A (existing motor joint) must spin gear B at the ratio — the marquee demo.
- Static/ground endpoint degenerate guards (zero radius, missing body) — never NaN.
- Placement onto the SAME body twice (self-gear) refuses like the self-joint precedent.
- Toothed-ring glyph stays screen-constant and does not regress the sprite-cache body rendering.
